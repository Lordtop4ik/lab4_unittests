# Документация проекта

## Общее описание
Geometric lib — это библиотека на Python для вычисления площадей и периметров различных геометрических фигур круга, прямоугольника, квадрата и треугольника.

Проект создан в рамках лабораторной работы по ИСРПО для обучения работе с Git и написания документации.

## Описание функций

### circle.py

**area(r)**
Принимает радиус круга r и возвращает его площадь.
Пример вызова:
```python
import circle

res = circle.area(5)
print(res)
```

**perimeter(r)**
Принимает радиус круга r и возвращает длину окружности.
Пример вызова:
```python
import circle

res = circle.perimeter(5)
print(res)
```

### rectangle.py

**area(a, b)**
Принимает стороны прямоугольника a и b, возвращает его площадь.
Пример вызова:
```python
import rectangle

res = rectangle.area(3, 4)
print(res)
```

**perimeter(a, b)**
Принимает стороны прямоугольника a и b, возвращает его периметр.
Пример вызова:
```python
import rectangle

res = rectangle.perimeter(3, 4)
print(res)
```

### square.py

**area(a)**
Принимает длину стороны квадрата a и возвращает его площадь.
Пример вызова:
```python
import square

res = square.area(4)
print(res)
```

**perimeter(a)**
Принимает длину стороны квадрата a и возвращает его периметр.
Пример вызова:
```python
import square

res = square.perimeter(4)
print(res)
```

### triangle.py

**area(a, h)**
Принимает сторону a и высоту h, возвращает площадь треугольника.
Пример вызова:
```python
import triangle

res = triangle.area(3, 4)
print(res)
```

**perimeter(a, b, c)**
Принимает три стороны треугольника a, b, c и возвращает его периметр.
Пример вызова:
```python
import triangle

res = triangle.perimeter(3, 4, 5)
print(res)
```

## План и результаты тестирования (Лабораторная работа №4)

### 1. Цели и задачи тестирования
- Автоматизированная проверка корректности математических вычислений площади и периметра фигур библиотеки `geometric_lib`.
- Реализация модульных тестов с использованием стандартной библиотеки Python `unittest`.
- Исследование работы функций на граничных значениях (0) и некорректных входных данных (отрицательные числа, нарушение геометрических аксиом).
- Тестирование методом «черного ящика» (исходный код функций не изменяется) и документирование выявленных дефектов.

### 2. Описание тестируемого продукта
`geometric_lib` — библиотека для вычисления площадей и периметров геометрических фигур (круг, прямоугольник, квадрат, треугольник). В рамках работы проверяется стабильность и математическая точность существующей реализации.

### 3. Область тестирования
- Функции площади: `circle.area(r)`, `square.area(a)`, `rectangle.area(a, b)`, `triangle.area(a, h)`.
- Функции периметра: `circle.perimeter(r)`, `square.perimeter(a)`, `rectangle.perimeter(a, b)`, `triangle.perimeter(a, b, c)`.

### 4. Стратегия тестирования
- Модульное функциональное тестирование методом «черного ящика».
- Применение методов эквивалентного разбиения и анализа граничных значений.
- Размещение тест-кейсов в отдельных файлах внутри пакета `tests/`.

### 5. Критерии приемки
- 100% прохождение позитивных тестов на корректных входных данных.
- Фиксация ошибок на негативных тестах как отчета о дефектах библиотеки.

### 6. Ожидаемые результаты
- На корректных положительных значениях результаты соответствуют формулам геометрии.
- На некорректных аргументах (отрицательные числа, невозможные фигуры) ожидается генерация исключения `ValueError`.
